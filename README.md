# PO AI Daily

Reconstruction of the visible daily product owner practice concept. Includes 12 rotating scenarios, local reflection journal and streak, a user-story drafting template, prioritization discussion prompts, and an acceptance-criteria checklist. Everything runs in the browser; there is no connected AI service, account, or shared data store.

The live site required ChatGPT sign-in and its lesson source could not be inspected. The existing `AWEMISSIONS/PO-AI-Daily` repository had no usable code. This rebuild is based on the directory description and visible login page; it is new practice content, not recovered original lessons.
